# 日本株価自動蓄積システム (Japan Stock Tracker)

GitHub Actionsを活用して、主要日本株10銘柄の日足および15分足データを自動収集・蓄積する完全無料のオープンソースシステムです。

Pythonスクリプト側で **株式分割対応 (Split-Adjusted)** および **MA(5/25/75/200), RSI(14), MACD(12,26,9), ボリンジャーバンド(20, ±2σ), ATR(14), 52週高値(過去252日High最大値)** を事前計算してCSVに記録するため、AI（Claude / ChatGPT / Gemini）に計算負荷をかけず、無料枠の最小トークンで最高精度の投資診断を実現します。

## ⏰ 自動実行スケジュール
- 📊 **日足＆テクニカル指標取得**: 平日 **16:00 JST** (07:00 UTC) ➔ `data/daily/{ticker}.csv` に新規営業日を追記・全指標再計算 ＆ `data/latest_summary.csv`（直近3営業日サマリー）を更新
- ⏱️ **15分足データ取得**: 平日 **11:20 JST** (02:20 UTC) ➔ `data/intraday/{ticker}.csv` に直近5日間の15分足を上書き更新

---

## 🚀 導入手順（3分で完了）

1. GitHubで新規リポジトリ `japan-stock-tracker` を **Public**（公開）で作成します。
2. 本リポジトリの全ファイルをアップロードしてコミットします。
3. リポジトリの **Settings** > **Actions** > **General** を開きます。
4. **Workflow permissions** で **"Read and write permissions"** にチェックを入れて **Save** します。
5. （任意・推奨）**Actions** タブから手動実行ボタンを押すか、ローカルで `python scripts/init_history.py` を実行すると、既存のCSVを保持したまま過去2年分の日足を自動補完し、全指標が即座に生成されます。
